# Aníbal Oliveira, portfolio 2027

Static site, published with GitHub Pages.

- Pages are built from the fragments in `_build/src` by `python3 _build/build.py`, which adds the shared header, footer, side navigation, metadata and previous/next links. Edit a fragment, run the script, commit both.
- One stylesheet (`site.css`) and one script (`site.js`) serve every page.
- Images and videos are in `imgs/`.
